# Phase 4: HTML Output

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Every task is tests-first and ends with a focused test and commit.

**Goal:** Render deterministic HTML tables with modern and historical-inspired themes.

**Architecture:** Rendering consumes `LogTable` only. Theme selection controls CSS classes and typography; calculation is never repeated.

**Tech Stack:** Python 3.14+, standard-library `html` and `pathlib`, pytest, CSS.

## Global Constraints

- All user-controlled text is HTML-escaped.
- Generated bytes are UTF-8 and newline-stable.
- The historical theme is an inspiration, not a claim of exact typeface reproduction.
- The `NAPIER` theme provides period typography for the plain N/log listing only. The full seventeenth/eighteenth-century structure — period notation, folio layout, difference columns, rounding marks — is owned by Phase 8 (`08-period-format`) and must not be duplicated here.

**Goal:** Render a complete, stable, friendly HTML table with modern and Napier-inspired themes.

**Depends on:** Phase 3 `LogTable` and generator.

**Produces:** `themes.py`, `render_html.py`, CSS, HTML escaping and snapshot-like structure tests.

**Files:** `src/napier_tables/themes.py`, `src/napier_tables/render_html.py`, `web/styles.css`, `tests/test_render_html.py`.

## Public symbols

- `class Theme(str, Enum)`: `MODERN`, `NAPIER`.
- `theme_class(theme: Theme) -> str`.
- `render_html(table: LogTable, theme: Theme = Theme.MODERN, title: str | None = None) -> str`.
- `write_html(table: LogTable, output_path: Path, theme: Theme = Theme.MODERN, title: str | None = None) -> None`.

## Tasks

### 4.1 Theme enum and CSS contract

Write failing tests for enum values, CSS class names, and the presence of modern sans-serif and historical serif font stacks. Implement `Theme` and `theme_class()`; add `web/styles.css` with `.theme-modern`, `.theme-napier`, table layout, responsive overflow, and print rules. Run `python -m pytest tests/test_render_html.py -k theme -q`; commit `feat: add HTML presentation themes`.

### 4.2 HTML document renderer

Write failing tests requiring `<!doctype html>`, escaped title/config values, a linked stylesheet, theme class, table headers, one row per `LogRow`, and four preserved fractional digits in the base-10 example. Implement `render_html()` using `html.escape`, deterministic attribute ordering, and `scaled_to_text()`; it must never call the calculation engine. Run `python -m pytest tests/test_render_html.py -k render -q`; commit `feat: render logarithm tables as HTML`.

### 4.3 File writer

Write failing tests for nested output paths, UTF-8 encoding, and byte-stable repeated writes. Implement `write_html()` with `Path.parent.mkdir(parents=True, exist_ok=True)` and `write_text(..., encoding="utf-8", newline="\n")`. Run `python -m pytest tests/test_render_html.py -k write -q`; commit `feat: write deterministic HTML files`.

### 4.4 Theme acceptance

Write tests that render both themes and assert the same table data appears in each while only theme-specific classes/styles differ. Verify the historical theme uses serif typography, ruled borders, and restrained colors rather than decorative image assets. Run `python -m pytest tests/test_render_html.py -q`; commit `test: verify modern and historical HTML themes`.

### 4.5 HTML handoff

Run `python -m pytest -q` and `git diff --check`. Handoff: Phase 5 serves the output of `write_html()` and must preserve the generated file bytes. Commit `docs: record HTML output handoff`.
